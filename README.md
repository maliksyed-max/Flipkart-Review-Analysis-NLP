# Flipkart Review Analysis using NLP

## 📌 About the Project

This project analyzes customer reviews from Flipkart using Natural Language Processing (NLP) techniques. The goal is to process textual reviews and extract useful information from customer feedback.

## 🎯 Objective

- Analyze customer reviews collected from Flipkart.
- Preprocess and clean textual review data.
- Apply NLP techniques to understand customer feedback.
- Identify patterns and useful information from the reviews.
- Gain practical experience in text preprocessing and NLP.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- NLTK
- Matplotlib
- Seaborn

## 📂 Project Files

- `CUSTOMER REVIEW ANALYSIS USING NLP.py` - Python implementation of the NLP analysis.
- `flipkart_reviews.xlsx` - Dataset containing customer reviews.

## 🔎 Methodology

1. Load the customer review dataset.
2. Clean and preprocess the text.
3. Perform text processing using NLP techniques.
4. Analyze the processed reviews.
5. Visualize and interpret the results.

## ▶️ How to Run

Install the required libraries:

```bash
pip install pandas numpy nltk matplotlib seaborn openpyxl
```
Run the program:
```
python "CUSTOMER REVIEW ANALYSIS USING NLP.py"
```

📚 Key Learning
This project provided practical experience with text preprocessing, Natural Language Processing, data analysis and extracting insights from customer reviews.
